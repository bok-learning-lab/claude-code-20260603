recentering-academics / folder index

A workshop project scaffold whose inputs are the Harvard College Fields of Concentration descriptions for academic year 2026–2027. Operations and outputs are open for the workshop attendee to fill in. Start with summary.md; everything else is here for browsing.

Top-level

  • summary.md — what this project is, how it was assembled, and the operations it invites
  • index.md / index.html — this file

inputs/

  • inputs/fields-of-concentration.pdf — the source PDF (Harvard College Fields of Concentration 2026–2027)
  • inputs/fields-of-concentration/
    • primary/ — every primary field, one markdown file per field, with provenance frontmatter
    • secondary/ — every secondary field, parallel structure

operations/

Empty. The substantive work — what skills, prompts, or operations to apply to the corpus — is open. See the summary's "What you can translate this to" section for candidate operations.

outputs/

Empty. Generated artifacts (advising handouts, comparative analyses, vocabulary studies, etc.) land here.
